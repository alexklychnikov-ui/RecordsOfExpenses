# Калькулятор расходов - Telegram Bot

Простое приложение для учёта расходов через Telegram с локальной базой данных SQLite.

## Возможности

- ➕ **Добавление расходов** — диалог с полем покупки (40 симв), выбор категории кнопками, календарь для даты
- 📋 **Просмотр списка** — все записи с информацией о покупке, категории, дате и сумме
- 📊 **Отчёт за месяц** — автоматический фильтр текущего месяца с разбивкой по категориям
- ✏️ **Редактирование** — пошаговое изменение всех полей с подстановкой текущих значений
- 🗓️ **Inline-календарь** — удобный выбор даты с навигацией по месяцам
- 🏷️ **Фиксированные категории** — еда, авто, быт, животные
- 💾 **Надёжное хранение** — SQLite с WAL-режимом

## Установка

### 1. Клонировать проект
```bash
git clone https://github.com/alexklychnikov-ui/RecordsOfExpenses.git
cd RecordsOfExpenses
```

### 2. Создать виртуальное окружение
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

Если возникает ошибка ExecutionPolicy:
```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned -Force
```

### 3. Установить зависимости
```powershell
python -m pip install -U pip
pip install -r requirements.txt
```

### 4. Настроить токен бота
Создайте `.env` файл:
```env
BOT_TOKEN=ваш_токен_от_BotFather
DB_PATH=expenses.db
```

Получить токен: напишите [@BotFather](https://t.me/BotFather) в Telegram → `/newbot`

### 5. Запустить бота
```powershell
python main.py
```

## Интерфейс бота

### Главное меню (кнопки)

После `/start` появляется меню с кнопками:

- **Добавить** — добавление нового расхода
- **Список** — просмотр всех записей
- **Посмотреть за месяц** — отчёт за текущий месяц
- **Редактировать** — редактирование записи по ID

## Формат дат

Все даты вводятся в формате `dd.mm.yyyy` (например, `28.10.2025`)

Можно также писать:
- `today` или `сегодня` — текущая дата

## Технические детали

### База данных
```sql
CREATE TABLE expenses (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    purchase TEXT NOT NULL,      -- до 40 символов
    category TEXT NOT NULL,      -- еда/авто/быт/животные
    date_iso TEXT NOT NULL,      -- YYYY-MM-DD
    amount INTEGER NOT NULL      -- в копейках
);
```

- **SQLite** с WAL-режимом для надёжности
- **Автоматическая миграция** при добавлении поля `purchase`
- **Параметризованные запросы** для защиты от SQL-injection

### Форматы данных
- **Суммы**: хранение в копейках (integer), отображение `123.45`
- **Даты**: хранение ISO `yyyy-mm-dd`, отображение `dd.mm.yyyy`
- **Покупки**: максимум 40 символов
- **Категории**: фиксированный список (еда, авто, быт, животные)

### Технологии
- **Python 3.13+**
- **Aiogram 3.10+** — асинхронный фреймворк для Telegram Bot API
- **SQLite** — локальная база данных
- **FSM (Finite State Machine)** — управление диалогами

## Отладка

### Логирование
Aiogram выводит логи в консоль. Для подробной отладки добавьте в `main.py`:
```python
import logging
logging.basicConfig(level=logging.DEBUG)
```

### Проверка БД
```powershell
sqlite3 expenses.db
sqlite> SELECT * FROM expenses;
sqlite> .quit
```

### Остановка бота
```powershell
# Ctrl+C в терминале (если запущен обычным образом)

# Или принудительно
taskkill /F /IM python.exe
```

### Проблема ExecutionPolicy (Windows)
Если при активации venv появляется ошибка:
```powershell
# Вариант 1: разрешить для текущего пользователя
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned -Force

# Вариант 2: использовать .bat вместо .ps1
venv\Scripts\activate.bat
```

### Конфликт экземпляров бота
Если бот пишет "Conflict: terminated by other getUpdates request":
```powershell
# Убить все процессы Python
taskkill /F /IM python.exe

# Запустить заново
python main.py
```
