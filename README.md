# Калькулятор расходов - Telegram Bot

Простое приложение для учёта расходов через Telegram с локальной базой данных SQLite.

## Возможности

- ➕ **Добавление расходов** с inline-календарём и кнопками категорий
- 📋 **Просмотр списка** с фильтрами по категории и датам
- 💰 **Подсчёт суммы** с фильтрацией
- 📊 **Отчёты за месяц** с разбивкой по категориям
- 📤 **Экспорт в CSV** для Excel/Google Sheets
- ✏️ **Редактирование** и удаление записей
- 🗓️ **Календарь** для выбора даты
- 🏷️ **Кнопки категорий** для быстрого доступа

## Установка

### 1. Клонировать проект
```bash
cd RecordsOfExpenses
```

### 2. Создать виртуальное окружение
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

Если возникает ошибка ExecutionPolicy:
```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned -Force
```

### 3. Установить зависимости
```powershell
python -m pip install -U pip
pip install -r requirements.txt
```

### 4. Настроить токен бота
Создайте `.env` файл:
```env
BOT_TOKEN=ваш_токен_от_BotFather
DB_PATH=expenses.db
```

Получить токен: напишите [@BotFather](https://t.me/BotFather) в Telegram → `/newbot`

### 5. Запустить бота
```powershell
python main.py
```

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Запустить бота и показать меню |
| `/add` | Добавить расход (с календарём и категориями) |
| `/list [фильтры]` | Список расходов |
| `/sum [фильтры]` | Сумма расходов |
| `/month [mm.yyyy]` | Отчёт за месяц |
| `/export [фильтры]` | Экспорт в CSV |
| `/edit` | Редактировать запись |
| `/delete <id>` | Удалить запись |
| `/help` | Справка |

### Примеры использования

```
/add
→ Сумма? 500
→ [Выбор категории из кнопок или ввод новой]
→ [Выбор даты из календаря]
→ Добавлено #1: 500.00 еда 28.10.2025

/list
→ [Кнопки с категориями для фильтра]

/list еда с 01.10.2025 по 31.10.2025
→ Список расходов по категории за период

/month
→ Отчёт за текущий месяц с разбивкой по категориям

/month 10.2025
→ Отчёт за октябрь 2025

/export еда с 01.10.2025 по 31.10.2025
→ CSV-файл с расходами категории "еда" за период

/sum
→ Общая сумма всех расходов

/edit
→ ID записи? 1
→ Что меняем? date
→ [Календарь для выбора новой даты]
```

## Формат дат

Все даты вводятся в формате `dd.mm.yyyy` (например, `28.10.2025`)

Можно также писать:
- `today` или `сегодня` — текущая дата

## Технические детали

- **База данных**: SQLite с WAL-режимом для надёжности
- **Формат сумм**: Хранится в копейках (integer), отображается как `123.45`
- **Формат дат**: Внутри ISO (`yyyy-mm-dd`), отображается `dd.mm.yyyy`
- **Бот**: Aiogram 3.x (асинхронный)
- **Состояния**: FSM для диалогов добавления и редактирования
- **Безопасность**: Параметризованные SQL-запросы

## Отладка

### Логирование
Aiogram выводит логи в консоль. Для подробной отладки добавьте в `main.py`:
```python
import logging
logging.basicConfig(level=logging.DEBUG)
```

### Проверка БД
```powershell
sqlite3 expenses.db
sqlite> SELECT * FROM expenses;
sqlite> .quit
```
